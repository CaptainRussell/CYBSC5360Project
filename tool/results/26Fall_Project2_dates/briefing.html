The eleven checks

How the tool checks it
  1. Windows logs every change to a file's details in the change journal ($UsnJrnl:$J) as a BasicInfoChange entry, stamped with the journal's own clock.
  2. The file's record-changed date ($STANDARD_INFORMATION, “E”) is the moment its details last changed, so it should be at or after the latest such journal entry.
  3. If it is earlier by more than 2 seconds, the date was set back after the change was logged.

How the tool checks it

How the tool checks it
  1. NTFS dates count in steps of 100 nanoseconds, seven digits after the second, so a real date almost never ends in exactly .0000000.
  2. Many date-changing tools write whole seconds.
  3. If the visible created or modified date has all seven sub-second digits zero, the check finds something.
