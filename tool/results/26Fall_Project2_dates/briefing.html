HOW IT WORKS

The idea in one line

Windows records the same event in several places, written by different parts of the system. A cover-up can change one or two of them, but keeping them all agreeing is hard — so disagreement is the clue. The tool runs eleven checks for disagreement and weighs them together, so one noisy check never raises an alarm on its own.

CheckPlain nameWhat it looks for
R1Record-change date is before the journal's own entryThe file's record says it last changed before Windows' change journal recorded that change.
R2A shortcut disagrees on the last-change dateA shortcut pointing at the file carries a different last-change date from the file itself.
R3A shortcut is older than the file it points toA shortcut was created before the file it points to claims to have existed.
R4A shortcut was opened after the file's last-opened dateA shortcut records the file being opened later than the file's own last-opened date.
R5The file changed while nobody was logged onThe file's dates fall outside every logged-on session in the event log.
R6The visible date is older than the protected copyThe creation date Windows shows is earlier than the file system's own protected copy.
R7The date was set to a round numberThe date falls exactly on a whole second, which ordinary activity almost never produces.
R8The file was created later than its visible dateThe change journal first recorded the file being created after the date it now shows.
R9A shortcut remembers a different creation dateA shortcut kept an older copy of the file's creation date that no longer matches.
R10The date changed as an unusual program ranThe file's date changed at the same moment a program not associated with it ran.
R11It claims to be much older than its neighborsThe file claims to pre-date the files whose records sit next to it on the disk.
METHOD & WORDS

How to read the score, and the fine print

Each file's score is the weighted share of the checks that disagreed, out of the checks that could be run, as a number from 0 to 100. A file is flagged when its score is above 50. Flagged files are “Look first” when they score 50 or more with at least two checks disagreeing, and “Worth a look” otherwise. Weighting mode: full.
