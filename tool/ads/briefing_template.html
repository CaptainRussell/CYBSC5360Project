The files most worth a closer look

  
Each file gets a score from 0 to 100: how much of what was checked looked wrong. Rare clues count for more than common ones. A high score is a reason to look, not proof of anything.

07 · WORDS AND METHOD
Words used in this report, and how the score works

  

  

    
How the score is worked out
      Each of the eight questions only counts if it makes sense for that file (a text file cannot be password-locked the way a Word file can). Each question gets a weight: the rarer its answer is on this drive, the more it counts. The score is the weighted share of a file's questions that found something wrong, shown out of 100.
